Both tracks plug into the same underlying process CA already uses for client work — this is the backbone for how you brief Claude on any task:

  1. Establish the basics — client, objective, audience, geography, budget, decision-maker.
  2. Bring real inputs — brand guidelines, competitor context, approved assets, not a summary from memory.
  3. Confirm scope and exclusions so Claude doesn't draft outside what's agreed.
  4. Use proper access for ad platforms, analytics and hosting — never paste credentials into a prompt.
  5. Draft — code, copy, structure, whatever the task calls for.
  6. Route for human review before anything reaches a client.
  7. Verify destinations, tracking and dates before launch.
  8. Report honestly, including limitations — a click is not a sale, a lead is not a booking.
This portal will expand to cover MCP connectors, folder and project management, pulling and pushing changes, running terminal sessions, Claude Code vs. Claude Cowork vs. chat, and Skills — as that material is added.
